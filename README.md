# Honda K-Line Smart Gauge

สมาร์ทเกจสำหรับมอเตอร์ไซค์ Honda หัวฉีดที่ใช้สาย K-Line บนบอร์ด ESP32-2432S028 (CYD จอ 2.8")
อ่านค่าเซนเซอร์สด อ่านโค้ดเสีย และลบโค้ด

## ไฟล์ที่ได้จากการคอมไพล์ (หน้า Releases → latest)

| ไฟล์ | ใช้ตอนไหน |
|---|---|
| `honda-gauge-st7789-full.bin` | แฟลชครั้งแรกผ่าน USB ที่ address `0x0` (บอร์ด USB 2 ช่องส่วนใหญ่) |
| `honda-gauge-ili9341-full.bin` | ใช้แทนตัวบน ถ้าสีจอเพี้ยนหรือจอขาว |
| `...-ota.bin` | อัปเดตผ่าน WiFi จากเมนู SET → WIFI UPDATE |

## หน้าจอ

- **GAUGE** รอบเครื่อง, อุณหภูมิเครื่อง, อุณหภูมิอากาศ, ไฟแบต, ลิ้นเร่ง %, MAP, ความเร็ว
- **DTC** อ่านโค้ดเสีย (ปัจจุบัน/อดีต) และลบโค้ด (กด CLEAR แล้วกด SURE? อีกครั้ง)
- **RAW** อ่านตารางข้อมูลดิบจาก ECU ไว้แกะข้อมูลรุ่นใหม่
- **SET** DEMO, TX INVERT, กลับสีจอ, กลับทิศทัช, อัปเดตผ่าน WiFi, ทดสอบสี

## การต่อสาย (ช่อง Expansion 3.3V / IO27 / IO22 / GND)

| CYD | วงจร K-Line |
|---|---|
| IO27 | TX |
| IO22 | RX |
| 3.3V | VCC ฝั่งลอจิก (เฉพาะ L9637D/โมดูล) |
| GND | GND |

ไฟเลี้ยงบอร์ด: Mini560 5V → ขา VIN + GND บนขั้ว Serial (ห้ามต่อ 12V ตรง)

**TX INVERT** ในหน้า SET: เปิด (ON) ถ้าใช้วงจรทรานซิสเตอร์, ปิด (OFF) ถ้าใช้ L9637D หรือโมดูลสำเร็จ

## หมายเหตุ

- ตาราง 0x11 (ค่าเซนเซอร์) ใช้รูปแบบที่พบในรถ Honda หลายรุ่น บางรุ่นอาจเรียงต่างกัน ดูหน้า RAW แล้วแจ้งเพื่อปรับ
- การอ่านโค้ดเสียยังเป็นรุ่นทดลอง ต้องทดสอบกับรถจริง
- ลบโค้ดแล้วถ้ายังไม่ซ่อมจุดเสีย โค้ดจะกลับมา
