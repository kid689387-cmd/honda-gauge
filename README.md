# อู่ช่างวัตร ฟรีดอม — Honda K-Line Smart Gauge

สมาร์ทเกจสำหรับมอเตอร์ไซค์ Honda หัวฉีดที่ใช้สาย K-Line บนบอร์ด ESP32-2432S028 (CYD จอ 2.8")
อ่านค่าเซนเซอร์สด อ่านโค้ดเสีย และลบโค้ด

## ไฟล์ที่ได้จากการคอมไพล์ (หน้า Releases → latest)

| ไฟล์ | ใช้ตอนไหน |
|---|---|
| `honda-gauge-ili9341-full.bin` | แฟลชครั้งแรกผ่าน USB ที่ address `0x0` (บอร์ดที่ทดสอบแล้ว HW-458) |
| `honda-gauge-st7789-full.bin` | ใช้แทนตัวบน ถ้าจอขาวหรือสีเพี้ยน |
| `...-ota.bin` | อัปเดตผ่าน WiFi จากเมนู SET → WIFI UPDATE |

## หน้าจอ (v0.3)

แตะหน้าเกจเพื่อเปิดเมนู มี 8 หน้า

- **เกจ** วงโค้งรอบเครื่อง ความเร็ว อุณหภูมิเครื่อง และ BAT / TPS / MAP / IAT
- **ข้อมูล** ค่าทั้งหมด 14 ค่า (INJ, IGN, O2, STFT/LTFT แสดง -- จนกว่าจะยืนยันกับรถจริง)
- **ตรวจเช็ก** เทียบค่ากับช่วงแนะนำทั่วไปตอนเดินเบา (ไม่ใช่ค่าเฉพาะรุ่น)
- **รหัสเสีย** อ่าน/ล้าง พร้อมคำอธิบายภาษาไทย
- **สถิติ** ค่าสูงสุด ชั่วโมงเครื่อง จำนวนสตาร์ต ตัวนับน้ำมันเครื่อง (บันทึกเฉพาะตอนต่อรถจริง)
- **กราฟ** รอบและอุณหภูมิ 30 วินาทีล่าสุด
- **K-LINE** อ่านตารางข้อมูลดิบจาก ECU
- **ตั้งค่า** ความสว่าง โหมดกลางวัน/กลางคืน รอบสูงสุดของเกจ กลับสี/ทัช โหมดสาธิต TX กลับขั้ว อัปเดต WiFi

## ทดสอบหน้าจอบนคอมพิวเตอร์

`tools/sim/run.sh` วาดทุกหน้าลงไฟล์ `tools/sim/out/sheet.png` โดยไม่ต้องใช้บอร์ด

## การต่อสาย (ช่อง Expansion 3.3V / IO27 / IO22 / GND)

| CYD | วงจร K-Line |
|---|---|
| IO27 | TX |
| IO22 | RX |
| 3.3V | VCC ฝั่งลอจิก (เฉพาะ L9637D/โมดูล) |
| GND | GND |

ไฟเลี้ยงบอร์ด: Mini560 5V → ขา VIN + GND บนขั้ว Serial (ห้ามต่อ 12V ตรง)

**TX INVERT** ในหน้า SET: เปิด (ON) ถ้าใช้วงจรทรานซิสเตอร์, ปิด (OFF) ถ้าใช้ L9637D หรือโมดูลสำเร็จ

## หมายเหตุ

- ตาราง 0x11 (ค่าเซนเซอร์) ใช้รูปแบบที่พบในรถ Honda หลายรุ่น บางรุ่นอาจเรียงต่างกัน ดูหน้า RAW แล้วแจ้งเพื่อปรับ
- การอ่านโค้ดเสียยังเป็นรุ่นทดลอง ต้องทดสอบกับรถจริง
- ลบโค้ดแล้วถ้ายังไม่ซ่อมจุดเสีย โค้ดจะกลับมา
